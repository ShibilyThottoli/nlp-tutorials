# NLP Tutorials

A collection of hands-on tutorials and practice notebooks covering
Natural Language Processing (NLP) and related Python tools.

## Topics

- Text preprocessing and tokenization
- Stemming and lemmatization
- Text vectorization and TF-IDF
- spaCy
- Hugging Face Transformers
- Tokenizers and embeddings
- NLP model experiments

## Technologies

- Python
- Jupyter Notebook
- spaCy
- Hugging Face Transformers
- scikit-learn

## Getting Started

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies required by the tutorial you want to run.
4. Open the relevant notebook in Jupyter.

## Note

Model weights, downloaded checkpoints, virtual environments, and large
datasets are not intended to be stored in this repository.
